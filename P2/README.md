# P2 - Portfolio Repository with an Initial Commit

## Aim
To create and manage a portfolio project repository using Git and GitHub.

## Tools Required
- VS Code
- Git
- GitHub
- Terminal

## Commands Used

| Command | Description |
| `git init` | Initializes a Git repository |
| `git add .` | Adds files to the staging area |
| `git commit -m "Initial commit"` | Saves the first version of the project |
| `git log --oneline` | Displays commit history |
| `git remote -v` | Displays the connected remote repository |
| `git push -u origin main` | Pushes local commits to GitHub |

## Procedure
1. Opened the portfolio project in VS Code.
2. Used Git to manage the project files.
3. Checked the commit history using `git log --oneline`.
4. Checked the remote GitHub repository using `git remote -v`.
5. Verified the repository connection.

## Result
Successfully inspected the portfolio repository, its commit history and its connection to GitHub.

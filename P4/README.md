# P4 - GitHub README and Version Tags

## Aim
To understand the use of README files and version tags in GitHub.

## Tools Required
- VS Code
- Git
- GitHub
- Terminal

## Theory
A README file gives information about a project and explains its purpose. Git tags are used to mark important points in the project's history, such as a particular version or release.

## Commands Used
1. `touch P4/README.md` – Creates a README file.
2. `git add .` – Adds files to the staging area.
3. `git commit -m "Complete Practical 4"` – Saves the changes.
4. `git tag -a v1.0 -m "First lab version"` – Creates a version tag.
5. `git push` – Pushes commits to GitHub.
6. `git push origin v1.0` – Pushes the tag to GitHub.
7. `git tag` – Displays available tags.

## Procedure
1. Created a folder named P4.
2. Created a README file inside the folder.
3. Added details about the practical.
4. Committed the changes using Git.
5. Created a version tag named v1.0.
6. Pushed the commit and tag to GitHub.

## Result
Successfully practised using README files and Git version tags.

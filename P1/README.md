# P1 - Project Folder and Terminal Navigation

## Aim
To create a project folder and learn basic terminal navigation commands.

## Tools Required
- Mac Terminal
- macOS

## Commands Practised

| Command | Description |
| `pwd` | Displays the current directory |
| `ls` | Lists files and folders |
| `cd` | Changes the current directory |
| `cd ..` | Moves to the parent directory |
| `cd ~` | Opens the home directory |
| `mkdir` | Creates a new directory |
| `clear` | Clears the terminal screen |

## Procedure
1. Opened Terminal.
2. Navigated to the Desktop.
3. Created a folder named Web-Development-Lab.
4. Entered the folder using the cd command.
5. Checked the current location using pwd.
6. Used ls to view the folder contents.
7. Practised moving between directories.

## Result
Successfully created a project folder and practised basic terminal navigation commands.

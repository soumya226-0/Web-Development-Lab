
# Practical 10: Portfolio Header and Footer with Advanced Flexbox

## Aim
To create a simple portfolio webpage with a header and footer using CSS Flexbox.

## Description
In this practical, I created a portfolio webpage with navigation links, an introduction section and a footer. I used Flexbox to arrange the items in the header and footer.

## Concepts Used
- HTML
- CSS
- Flexbox
- Media Queries
- Responsive Design

## Files
- `index.html` – Contains the webpage structure.
- `style.css` – Contains the styling.

## Result
Successfully created a portfolio webpage with a Flexbox-based header and footer.

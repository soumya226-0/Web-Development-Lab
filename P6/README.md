# P6 - Full Portfolio Page Structure Using Semantic HTML

## Aim
To create a complete portfolio webpage using semantic HTML elements.

## Tools Required
- VS Code
- HTML
- Web Browser

## Theory
Semantic HTML helps organize a webpage into meaningful sections. Elements like header, nav, main, section, article and footer make the structure clear and easy to understand.

## HTML Elements Used
- `<header>` – Displays the portfolio heading.
- `<nav>` – Contains navigation links.
- `<main>` – Holds the main content.
- `<section>` – Divides content into different parts.
- `<article>` – Groups individual project details.
- `<footer>` – Displays the bottom section.

## Procedure
1. Created an HTML file named index.html.
2. Added the basic HTML structure.
3. Created navigation links for different sections.
4. Added About, Skills, Projects and Contact sections.
5. Used semantic HTML elements to organize the content.
6. Opened the file in a browser to check the webpage.

## Result
Successfully created a portfolio webpage using semantic HTML elements.

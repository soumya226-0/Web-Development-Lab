
# Practical 8: Sticky Navbar and Card Overlay

## Aim
To create a webpage with a sticky navigation bar and image cards using CSS positioning.

## Tools Used
- HTML
- CSS
- Visual Studio Code
- Web Browser

## Concepts Used
- position: sticky
- position: relative
- position: absolute
- z-index
- Flexbox

## Procedure
1. Created a webpage using HTML.
2. Added a navigation bar and destination cards.
3. Used CSS to style the webpage.
4. Applied sticky positioning to the navbar.
5. Used relative and absolute positioning for the image overlays.
6. Opened the webpage in a browser to check the output.

## Result
Successfully created a webpage with a sticky navbar and image cards containing text overlays.


# Practical 13: Choosing Between Flexbox and Grid for a Shared Layout

## Aim
To create a webpage using both CSS Flexbox and CSS Grid.

## Description
In this practical, I created a portfolio webpage containing a navigation bar, introduction section, project cards and footer. I used Flexbox for the header and navigation bar, while CSS Grid was used to arrange the project cards.

## Concepts Used
- HTML
- CSS
- Flexbox
- CSS Grid
- Media Queries
- Responsive Design

## Difference Between Flexbox and Grid
- Flexbox is mainly used to arrange items in one direction.
- Grid is used to arrange items in rows and columns.

## Files
- `index.html` – Contains the webpage structure.
- `style.css` – Contains the styling.

## Result
Successfully created a responsive portfolio webpage using both Flexbox and CSS Grid.

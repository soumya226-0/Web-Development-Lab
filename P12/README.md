
# Practical 12: Portfolio Projects Grid with Advanced CSS Grid

## Aim
To create a portfolio projects section using CSS Grid.

## Description
In this practical, I created a webpage containing six project cards. I used CSS Grid to arrange the cards into three columns. I also used grid-column to make the first card occupy two columns.

## Concepts Used
- HTML
- CSS
- CSS Grid
- Grid columns
- Grid gap
- Grid-column
- Media Queries
- Responsive Design

## Files
- `index.html` – Contains the webpage structure.
- `style.css` – Contains the styling and grid layout.

## Result
Successfully created a portfolio projects grid using advanced CSS Grid properties.

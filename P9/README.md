
# Practical 9: Responsive Navbar and Card Grid using Flexbox

## Aim
To create a responsive navigation bar and card layout using CSS Flexbox.

## Tools Used
- HTML
- CSS
- Visual Studio Code
- Web Browser

## Concepts Used
- CSS Flexbox
- display: flex
- justify-content
- align-items
- flex-wrap
- flex-direction
- Media Queries

## Procedure
1. Created a webpage using HTML.
2. Added a navigation bar and destination cards.
3. Used Flexbox to arrange the elements.
4. Added media queries for smaller screens.
5. Tested the webpage by resizing the browser window.

## Result
Successfully created a responsive webpage with a navigation bar and card grid that adjusts to different screen sizes.

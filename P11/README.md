
# Practical 11: Newspaper-style Three-column Layout with CSS Grid

## Aim
To create a newspaper-style webpage using CSS Grid.

## Description
In this practical, I created a simple newspaper webpage with three article sections. CSS Grid was used to arrange the articles in three equal columns.

## Concepts Used
- HTML
- CSS
- CSS Grid
- Grid columns
- Gap
- Media Queries
- Responsive Design

## Files
- `index.html` – Contains the webpage structure.
- `style.css` – Contains the styling and grid layout.

## Result
Successfully created a newspaper-style webpage with a three-column layout using CSS Grid.

# P7 - Design Tokens and Typography System in CSS

## Aim
To create a basic design system using CSS variables, colors, spacing and typography.

## Tools Required
- VS Code
- HTML
- CSS
- Web Browser

## Theory
Design tokens are reusable values used in CSS for colors, spacing and fonts. CSS variables help maintain consistency and make it easier to update the design. Typography controls the appearance and readability of text.

## CSS Properties Used
- `:root` – Defines global CSS variables.
- `--variable-name` – Creates a CSS variable.
- `var()` – Uses the stored variable.
- `font-family` – Sets the font style.
- `font-size` – Sets the text size.
- `padding` – Adds space inside an element.
- `margin` – Adds space outside an element.

## Procedure
1. Created index.html and style.css files.
2. Connected the CSS file to the HTML page.
3. Defined reusable color, spacing and font variables.
4. Applied the variables to different webpage elements.
5. Added headings, paragraphs and color boxes.
6. Opened the webpage in a browser to check the output.

## Result
Successfully created a simple CSS design system using reusable design tokens and typography styles.

# P5 - Semantic Bio Page

## Aim
To create a personal bio webpage using semantic HTML elements.

## Tools Required
- VS Code
- HTML
- Web Browser

## Theory
Semantic HTML elements describe the purpose of different parts of a webpage. They make the code easier to understand and maintain.

## HTML Elements Used
- `<header>` – Defines the top section of the page.
- `<nav>` – Contains navigation links.
- `<main>` – Contains the main content.
- `<section>` – Groups related information.
- `<footer>` – Defines the bottom section.

## Procedure
1. Created a file named index.html.
2. Added the basic HTML structure.
3. Used semantic elements to divide the webpage into sections.
4. Added personal information, education, interests and contact details.
5. Opened the webpage in a browser to check the output.

## Result
Successfully created a personal bio webpage using semantic HTML elements.
